# ANDROMEDA 4 — Landing page

Sitio estático y adaptable para presentar al equipo ANDROMEDA 4, del reto de cohetería del Tecnológico de Monterrey, Campus Sinaloa. Está construido con HTML, CSS y JavaScript, sin frameworks ni procesos de compilación.

## Archivos

- `index.html`: contenido y estructura del sitio.
- `styles.css`: identidad visual y diseño adaptable.
- `script.js`: menú móvil y cuenta regresiva visual.
- `assets/`: logotipos, póster de identidad y fotografías de integrantes.

## Identidad visual

- Azul noche: `#080F29`
- Violeta: `#8735F5`
- Turquesa: `#00E0E7`
- Blanco: `#FFFFFF`

## Contenido integrado

- Identidad institucional: Tecnológico de Monterrey, Campus Sinaloa.
- Misión y objetivo redactados a partir de las respuestas del equipo.
- Desarrollo colaborativo, sin inventar etapas no documentadas.
- Componente informado por el equipo: motor A10-3T.
- Resultados y aprendizaje: observación del movimiento del cohete.
- Perfiles, carreras y fotografías de los cinco integrantes, tomados del apartado de autores del PDF proporcionado.

No se incluyó una sección de historia ni una sección de avances, tal como indicó el equipo. Tampoco se inventaron funciones individuales, materiales, cálculos, pruebas o resultados técnicos no proporcionados.

## Ver el sitio localmente

Abre `index.html` en un navegador. También puedes usar la extensión Live Server de Visual Studio Code.

## Publicar en GitHub Pages

1. Crea un repositorio, por ejemplo `andromeda-4`.
2. Sube el contenido completo de esta carpeta, conservando la carpeta `assets`.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub Pages genere la dirección pública.

## Nota sobre la cuenta regresiva

La secuencia 3, 2, 1 es una animación visual de bienvenida. No representa una cuenta regresiva real de lanzamiento.
